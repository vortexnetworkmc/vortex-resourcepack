# Vortex Skyblock resource pack (branch `skyblock`)

This branch is ONLY for the Vortex Skyblock server (Folia 26.1.2). It shares no history with `main`, which holds the
Prisons (1.12.2) pack `vortex-skins.zip`; Prisons is unaffected by anything here.

- `vortex-skyblock.zip`: the built pack the Skyblock server offers to players (prompted, not forced).
- `assets/`, `pack.mcmeta`: the sources. Custom ores use unused `mushroom_stem` block states and `vortex:` item models.
- Textures are generated placeholders; replace them with final art and rebuild the zip.
